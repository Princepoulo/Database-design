Project: Green Valley Estate Database System
This project involves designing and implementing a centralized database system for Green Valley Estate to streamline operations across departments like Security, Maintenance, Finance, and Community Services. The solution addresses inefficiencies in manual record-keeping, improves data consistency, and enhances security.

Key Features:
Database Design: ERD, logical and physical data models with 15+ entities.

SQL Implementation: Tables, indexes, sequences, and views for performance optimization.

Sample Data: Populated tables with realistic data for testing.

Queries: Examples of complex queries for reporting and analytics.

What I Learned:
Database Design: Translating business rules into ERD and normalized tables.

SQL Optimization: Using indexes, sequences, and views for efficiency.

Query Writing: Advanced SQL techniques (joins, subqueries, aggregations).

Real-World Application: Solving operational challenges with a structured database.

Technologies: SQL (Oracle), Crow’s Foot Notation, Database Normalization.
